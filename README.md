# 🎹 Piano Rhythm Game

Um jogo de ritmo estilo Guitar Hero feito com Godot 4 usando arquivos MIDI convertidos para JSON 🎮✨

---

## 🚀 Funcionalidades

- 🎹 Sistema de notas baseado em MIDI
- 📁 Carregamento automático de músicas JSON
- 🔊 Reprodução de notas reais de piano
- ✨ Efeitos visuais e glow
- ⏱️ Sincronização por tempo real
- 🎼 Suporte para BPM variável
- 🎯 Spawn automático de blocos/notas
- 📜 Lista dinâmica de músicas

---

## 🛠️ Tecnologias

- 🎮 Godot 4
- 🐍 Python
- 🎵 MIDI
- 📄 JSON
